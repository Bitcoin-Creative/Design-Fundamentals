#  Guia de Contribuição

Obrigado pelo interesse em contribuir com o **Design Fundamentals** do Bitcoin Creative! 

Este repositório contém projetos open source desenvolvidos por participantes do programa de formação em design. Sua contribuição ajuda a comunidade Bitcoin a crescer.

---

##  Formas de Contribuir

###  Dar uma Estrela
A forma mais simples de contribuir! Estrelas ajudam a aumentar a visibilidade do projeto.

###  Reportar Problemas
Encontrou um erro ou tem uma sugestão? Abra uma [Issue](https://github.com/Bitcoin-Creative/Design-Fundamentals/issues/new).

###  Melhorar Documentação
- Corrigir erros de português
- Adicionar traduções (inglês, espanhol)
- Melhorar descrições dos projetos

###  Contribuir com Design
- Criar thumbnails para projetos que não têm
- Melhorar assets visuais
- Propor melhorias de UI/UX

###  Enviar Pull Requests
1. Faça um **Fork** do repositório
2. Crie uma **branch** para sua feature: `git checkout -b minha-contribuicao`
3. Faça **commit** das mudanças: `git commit -m 'Adiciona minha contribuição'`
4. Faça **push** para a branch: `git push origin minha-contribuicao`
5. Abra um **Pull Request**

---

##  Diretrizes

### Código de Conduta
- Seja respeitoso e inclusivo
- Foque em contribuições construtivas
- Respeite os autores originais dos projetos

### Padrões de Commit
Use mensagens claras e descritivas:
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` alteração de documentação
- `style:` formatação, sem mudança de código
- `refactor:` refatoração de código

### Créditos
Ao utilizar materiais deste repositório, dê crédito aos autores originais conforme a licença MIT.
